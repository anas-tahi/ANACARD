# ANACARD - Connect, Laugh, Bond

A modern, warm, and memorable digital platform designed to help people connect, laugh, and bond through real-life card experiences.

## 🌟 **Live Demo**: [https://anacard.onrender.com](https://anacard.onrender.com) 🎴✨

## 🌟 Features

### Core Functionality
- **5 Themed Card Decks**: Conversation Starters, Fun Dares, Would You Rather, Deep Questions, and Party Games
- **Interactive Card Mechanics**: Draw, shuffle, skip, and save cards
- **Timer System**: Built-in timer for dare cards (30s, 1m, 2m options)
- **Game Modes**: Everyone Answers mode and Host mode for parties
- **Mobile-First Design**: Responsive interface that works beautifully on any device
- **No Login Required**: Jump straight into the fun

### User Experience
- **Smooth Animations**: Card flip effects and transitions
- **Touch Support**: Swipe gestures on mobile devices
- **Keyboard Shortcuts**: Quick access to common actions
- **Saved Cards**: Keep your favorite prompts for later
- **Visual Feedback**: Clear indicators for all interactions

## 🚀 Quick Start

1. **Download or Clone** the project files
2. **Open `index.html`** in your web browser
3. **Click "Start Playing"** to begin
4. **Choose a deck** and start drawing cards!

That's it - no installation, no setup, no login required!

## 📱 How to Use

### Getting Started
1. Open the website in any modern browser
2. Click the "Start Playing" button on the landing page
3. Select your preferred deck from the 5 available options
4. Use the game controls to interact with cards

### Game Controls
- **Draw Card**: Reveals the next card in the deck
- **Shuffle**: Randomizes the entire deck
- **Skip**: Moves to the next card without saving
- **Save**: Adds the current card to your saved collection

### Special Features
- **Timer**: Automatically appears for dare cards with preset time options
- **Everyone Answers Mode**: Toggle for group participation
- **Host Mode**: Take control of the game flow
- **Saved Cards**: View and manage your favorite prompts

### Keyboard Shortcuts
- `Space/Enter`: Draw next card
- `S`: Save current card
- `R`: Shuffle deck
- `Right Arrow`: Skip card
- `Escape`: Close menu

### Mobile Gestures
- **Swipe Left**: Skip current card
- **Swipe Right**: Save current card
