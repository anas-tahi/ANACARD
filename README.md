## 🎮 What is ANACARD?

ANACARD turns awkward silences into memorable moments. Pick a deck, draw a card, and let the conversation flow.

## ✨ Features

- 🃏 **5 Themed Decks** — Conversation Starters, Dares, Would You Rather, Deep Questions, Party Games
- 🎨 Modern warm UI — clean, responsive, mobile-friendly
- ⚡ No account needed — just open and play
- ☁️ Live on Render

## 🚀 Run Locally

```bash
git clone https://github.com/anas-tahi/ANACARD
cd ANACARD
# Open index.html in your browser — no setup needed
```
